# Pause windows besides lunch

**From:** the owner, 2026-11-04 (during milestone M2 of 001) · **Status:** idea, not yet taken up

## What
Besides the lunch window, the person can declare further named pause windows, e.g. «Znüni» 09:30–10:00 or
«Zvieri» 15:00–15:30. A lock or standby pause inside such a window is deducted from the day's total, as the
lunch pause is. Several windows are possible. A pause outside every window still counts as work, as today.

## Why
Short breaks at fixed times are not work, but today only the lunch window deducts a pause, so they count as
working time.
