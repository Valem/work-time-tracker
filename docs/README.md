# Docs

The project's documentation, in one layout shared by every project.

```text
docs/
├── vision.md                    why the project exists, in the human's words — one per project, changed by commit, never tracked as a feature
├── architecture.md              what is built now — first written when 001-foundation closes, updated at every feature close
├── ideas/                       one file per idea
├── decisions/ADR-nnn-<slug>.md  project-wide decisions
└── features/NNN-<slug>/
    ├── brief.md
    └── concept.md
```
